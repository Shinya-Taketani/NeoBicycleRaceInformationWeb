## 4. 集計式・適格性・CI（集計前に固定）

```text
actual_rate = sum(I(official rank == k)) / eligible_entries
mean_predicted_probability = sum(saved position_k_probability) / eligible_entries
residual = actual_rate - mean_predicted_probability
```

正は過小評価、負は過大評価。表のppは率差×100。予測確率を除外後に再正規化しない。2年合算は件数加重（分子/分母の合算）で、年等重みでも年別値の置換でもない。登録人数N=count(input.entries)を車立てとして使用し、実発走人数で数え直さない。

### 不確実性

レースをクラスタ単位とし、同一raceのyとpを対にした残差から直接CIを計算する。本セルでは1 raceに同じbikeが最大1件なので、R個のraceの残差dについてCR1は次になる。

```text
SE(mean(d)) = sqrt(sum((d - mean(d))^2) / (R*(R-1)))
95%CI = mean(d) +/- 1.959963984540054 * SE
```

実績率・平均予測確率にも同じレース単位の近似区間を付す。残差CIを別々のCI端点の引算で作らない。1番−6番の差は共通適格raceで`(y1-p1)-(y6-p6)`を作り、race内共分散を保持した別CSVに保存した。

乱数seedは`NOT_USED_ANALYTIC_NO_RANDOM_RESAMPLING`（乱数/新bootstrapなし）。Welford法で分散を逐次計算し、重点24セルを別実装の和・二乗和で検証した。R<2はCI NULL、R<200はlow_supportを付す。200は解釈上の小標本注意表示であり、旧Gateや採否閾値を変更しない。小標本で範囲外になる正規近似CIをclipして見かけ上改善しない。

開催内/同一選手の繰返し依存、学習parameter不確実性、多重比較は未補正。CIは探索的参考値であり、有意差検定・独立車番効果・補正後性能の証明ではない。

## 10. 既存STAT39との重複

Stat39CalculatorはFIELD_BIKE/BASELINE等の過去得点期待残差を持ち、Bt02SignalRegistryは`features.FIELD_BIKE_DELTA.mean_score_expectation_residual`を元C1の12信号のindex10として使用する。両OuterモデルともSTAT39にactive係数10個、各1/2/3着の全10個が非ゼロだった（保存model/layout/係数だけを読んだ。再推論なし）。各groupの保存STAT39値平均もCSVに保持した。

既存残差は過去の着順percentile対得点percentileの残差delta、今回の残差は対象結果の二値入着対保存確率の差で、数式上は同じ量ではない。ただし車立て/車番/能力の関連を既にモデルへ接続しており、新しい車番加点と独立である保証はない。ablation/反実仮想予測/再fitを行っていないので「既存STAT39が説明済み」も「未説明の独立車番効果」も確定しない。

旧FIELD_BIKEカテゴリ追加実験は主Gate未達・不採用のまま。今回の較正残差を理由に再試行・別符号化・Gate変更を許可しない。
